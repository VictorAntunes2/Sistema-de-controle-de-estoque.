# Sistema de Controle de Estoque

Projeto desenvolvido em Python para gerenciamento simples de produtos.

## Funcionalidades

- Cadastro de produtos
- Listagem de produtos
- Busca de produtos
- Atualização de estoque
- Remoção de produtos

## Tecnologias

- Python 3

## Conceitos aplicados

- Listas
- Dicionários
- Loops
- Condicionais
- CRUD
- Estruturas de Dados
